# Public assets

Arquivos opcionais e substituíveis do portfólio:

- `images/felipe-schwabe.jpg` — retrato real usado na seção About.
- `images/felipe-schwabe-logo.png` — logo original usada no header.
- `images/showreel-poster.jpg` — poster do showreel.
- `images/projects/*-poster.jpg` — poster de cada projeto.
- `images/projects/*-still-01.jpg` até `*-still-03.jpg` — stills das páginas de projeto.
- `videos/showreel.mp4` — showreel principal, autoplay, muted e loop.
- `videos/projects/*.mp4` — vídeos principais dos projetos.
- `og-image.jpg` — imagem de compartilhamento social em 1200×630.

Enquanto esses arquivos não existem, a interface mostra placeholders editoriais próprios e não quebra a navegação.
